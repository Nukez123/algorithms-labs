Лабораторная работа 7

Используя словесное и визуальное описание реализовать сортировку пузырьком.

Словесное описание

  1. Сравниваем два соседних числа.
  2. Если левое число больше правого — меняем их местами.
  3. Продолжаем до конца массива: самое большое число окажется справа.
  4. Повторяем проходы, пока массив не будет отсортирован.

Визуальное описание

Фиолетовые столбики — два элемента, которые сравниваются на текущем шаге.

Нажми «Сортировать», чтобы увидеть столбики.
