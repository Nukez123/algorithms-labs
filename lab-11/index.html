Лабораторная работа 11

Используя словесное описание реализовать обход дерева.

Словесное описание

  1. Первое число становится корнем дерева. Меньшие числа добавляем слева, остальные — справа
  2. Симметричный обход: левое поддерево → корень → правое
  3. Прямой обход: корень → левое поддерево → правое
  4. Обратный обход: левое поддерево → правое → корень
  5. Поуровневый обход: просматриваем узлы по уровням слева направо
Результаты появятся здесь

Поуровневый обход

Узлы каждого уровня выводятся слева направо, начиная с корня
