Лабораторная работа 9

Используя словесное и визуальное описание реализовать сортировку выбором

Словесное описание

  1. Находим самое маленькое число в неотсортированной части массива
  2. Меняем его местами с первым элементом этой части
  3. Первый элемент теперь на своём месте — больше его не трогаем
  4. Повторяем для оставшихся чисел, пока массив не отсортируется
Результат появится здесь

Визуальное описание

Фиолетовый столбик - выбранный минимум на этом проходе; светло-фиолетовые - уже отсортированные элементы

Нажми «Сортировать», чтобы увидеть столбики
