Используя словесное описание реализовать работу с очередью

Словесное описание

  1. Очередь работает по принципу FIFO: первый добавленный элемент извлекается первым
  2. Новое число добавляется в конец очереди
  3. При извлечении удаляется первый элемент
  4. Для чисел в очереди можно вычислить сумму, среднее, минимум и максимум
